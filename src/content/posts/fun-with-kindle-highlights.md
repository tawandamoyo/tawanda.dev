My favorite software project is a [Kindle Highlights CLI Tool](https://github.com/tawandamoyo/kindle-tool-cli) that I built to manage the notes and highlights I make when reading on the Kindle ereader. Aside from its usefulness it made the idea of computers being incredible tools for small personal tasks more concrete, and has made me a better programmer.

My favorite feature is the command to generate random highlights, where you just run the tool's name followed by the path to the Kindle's `My Clippings.txt` file, as below:

```shell
nota random Desktop/My\ Clippings.txt
```

This prints out three random highlights to the terminal. You can also specify the number of highlights you want by adding the number as an option:

```shell
nota random Desktop/My\ Clippings.txt 5  # will print 5 highlights
```

Using this command I find interesting highlights that would otherwise lie forgotten and these sometimes trigger surprising ideas and insights. I sometimes end up rerunning the command multiple times and I never cease to be amazed by the amazing and profound things that humanity has put into writing over the centuries.

I have also recently started using Chat GPT, and I asked it how to further enhance the app and was surprised by the responses I got.
